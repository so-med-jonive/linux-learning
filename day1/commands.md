# Day 1 Commands

## pwd

Print the current working directory.

Example

```bash
pwd
```

---

## ls

List files and directories.

```bash
ls
```

```bash
ls -l
```

```bash
ls -la
```

---

## cd

Change directory.

```bash
cd Documents
```

```bash
cd ..
```

```bash
cd ~
```

---

## mkdir

Create a directory.

```bash
mkdir cloud-lab
```

---

## touch

Create a file.

```bash
touch notes.txt
```

---

## cp

Copy files.

```bash
cp notes.txt backup.txt
```

---

## mv

Move or rename files.

```bash
mv backup.txt archive.txt
```

---

## rm

Delete files.

```bash
rm archive.txt
```

---

## clear

Clear terminal.

```bash
clear
```

---

## history

Display command history.

```bash
history
```
